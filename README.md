# Application Web de Gestion d'Articles Multi-utilisateurs

Application web développée dans le cadre de mes projets académiques, permettant la gestion d'articles et l'interaction sociale entre utilisateurs.

## Fonctionnalités
- Authentification sécurisée, gestion des rôles utilisateurs et des droits d'accès.
- Opérations CRUD (Création, Lecture, Mise à jour, Suppression) sur les articles.
- Fonctionnalités sociales intégrées : système de likes et de commentaires

##  Technologies utilisées
- **Back-end :** PHP
- **Base de données :** MySQL
- **Front-end :** HTML5, CSS3 (Responsive Design)
- **Environnement de test :** XAMPP
